\SignalQuestion{1}{%
\textbf{1.} What does the following signal processing concepts mean?
Be clear, concise, and relevant.
\begin{enumerate}[label=\alph*),leftmargin=15pt,itemsep=2pt,topsep=3pt]
\item Sampling\hfill(1p)
\item Quantization\hfill(1p)
\item Impulse response\hfill(1p)
\item Frequency response\hfill(1p)
\item Windowing\hfill(1p)
\end{enumerate}
}

\SignalSolution{1}{a}{%
\textit{Graded reference answer: 1/1 point.}\par
\stepheading{Sampling}
Turn a continuous signal into a discrete signal by taking sample points at a
predetermined sampling frequency:
\[
S(t)\longrightarrow S(n).
\]
\noteheading{Final answer}
Sampling converts a continuous-time signal into a discrete-time signal by
taking measurements at regular time intervals.
\noteheading{Remember}
Sampling makes the time axis discrete.
}

\SignalSolution{1}{b}{%
\textit{Graded reference answer: 1/1 point.}\par
\stepheading{Quantization}
Quantization changes the set of possible values a signal can take.
The graded answer gives this image example:
\[
\text{8-bit pixel values}\longrightarrow\text{4-bit pixel values}.
\]
\textbf{English clarification:} A bit depth of $B$ permits $2^B$ levels:
\[
\begin{aligned}
\text{8 bits:}\quad 2^8&=256\text{ levels},\\
\text{4 bits:}\quad 2^4&=16\text{ levels}.
\end{aligned}
\]
\noteheading{Final answer}
Quantization maps a continuous range of signal values to a finite set of
discrete levels.
\noteheading{Remember}
Quantization makes signal values discrete.
}

\SignalSolution{1}{c}{%
\textit{Graded reference answer: 1/1 point.}\par
\stepheading{Impulse response}
The impulse response is a system's response, or output, to an impulse input.
\par
\textbf{English clarification:} Starting from rest, a unit impulse at the input
gives the impulse response at the output:
\[
\begin{aligned}
x[n]&=\delta[n],\\
y[n]&=h[n].
\end{aligned}
\]
\noteheading{Final answer}
The impulse response $h[n]$ is the output produced by a unit impulse input.
\noteheading{Remember}
Unit impulse in; impulse response out.
}

\SignalSolution{1}{d}{%
\textit{Graded reference answer: 1/1 point.}\par
\stepheading{Frequency response}
The frequency response describes how a system responds to an input signal
in the frequency domain.
For each frequency component, it tells us:
\begin{itemize}
\item how its amplitude is changed;
\item how its phase is shifted.
\end{itemize}
\noteheading{Final answer}
Frequency response describes the amplitude change and phase shift that a
system applies at different frequencies.
\noteheading{Remember}
Read amplitude change and phase shift as functions of frequency.
}

\SignalSolution{1}{e}{%
\textit{Graded reference answer: 1/1 point.}\par
\stepheading{Windowing}
We often want to process a signal over a shorter time interval.
Windowing truncates or limits the signal in a chosen way using a window function.
\par
Examples from the graded answer: rectangular, Hann, and Hamming windows.
\par
\textbf{English clarification:} Apply the window by multiplication:
\[
x_w[n]=x[n]w[n].
\]
Before Fourier analysis, the window can help control spectral leakage.
\noteheading{Final answer}
Windowing applies a window function to select and weight a finite segment
of a signal for analysis.
\noteheading{Remember}
The window chooses and weights the time segment.
}

\stepheading{1. Assumptions and output length}

The handwritten list stops at $n=4$.

\stepheading{2. Write the convolution sum}
Multiply overlapping samples and add:
\[
y(n)=\sum_{k=-\infty}^{\infty}s(k)h(n-k).

Only nonzero overlapping terms contribute.

\stepheading{3. Calculate $y(0)$}
Only the first samples overlap:

\textit{Reference: included example-solutions sheet.}\par
\noteheading{Differentiation}
The example solution identifies approximate differentiation: the filter
emphasizes changes in the signal.

\noteheading{English clarification:}
Index the listed coefficients from $h(0)$ and keep their given order.
The three taps give:
\[
\begin{aligned}
y(n)&=-0.5s(n)\\
    &\quad+0s(n-1)\\
    &\quad+0.5s(n-2).
\end{aligned}
\]
The middle tap is zero, leaving a scaled difference:
\[
y(n)=\frac{s(n-2)-s(n)}{2}.
\]
The given tap order takes an older sample minus a newer one, so it reverses the

\stepheading{Why constant levels disappear}
In a constant region, $s(n)=s(n-2)=C$:
\[
\begin{aligned}
y(n)&=-0.5C+0.5C\\

\end{aligned}
\]
Constant/DC levels cancel, while changes can produce a response.
This explains the reference's high-pass interpretation near DC.

\noteheading{Final answer}
\textbf{Approximate differentiation: a finite-difference filter.}
It suppresses constant levels and emphasizes changes in the signal.

\noteheading{Remember}
Opposite-sign taps compare samples; their zero sum cancels a constant level.

\SignalSolution{3}{b}{%
\textit{Your method: input group + feedback group, then combine.}\par
\noteheading{Read the blocks}
Each $T$ adds one sample of delay.
Multiply each branch by its gain, then add the terms entering the sums.

\stepheading{1. Input group}
Follow the branches starting at $x(n)$:
\[
\begin{aligned}
\text{No delay:}\quad &1\cdot x(n)=x(n),\\
\text{One delay:}\quad &2x(n-1),\\
\text{Three delays:}\quad &1\cdot x(n-3)=x(n-3).
\end{aligned}
\]
There is no branch into a sum after the second $T$, so there is no $x(n-2)$ term.
Add the input terms:
\[
\begin{aligned}
\text{Input group}&=x(n)+2x(n-1)\\
                &\quad+x(n-3).
\end{aligned}
\]

\stepheading{2. Feedback group}
Now start at $y(n)$ and follow the return branches.
Use this exam's gains, $-3$ and $+2$:
\[
\begin{aligned}
\text{One delay:}\quad &-3y(n-1),\\
\text{Three delays:}\quad &2y(n-3).
\end{aligned}
\]
The second delay has no branch into the sum, so there is no $y(n-2)$ term.
Add the feedback terms:
\[
\text{Feedback group}=-3y(n-1)+2y(n-3).
\]

\stepheading{3. Combine at the output}
The final $+$ adds your two groups:
\[
y(n)=\text{Input group}+\text{Feedback group}.
\]
Substitute the grouped terms:
\[
\begin{aligned}
y(n)&=x(n)+2x(n-1)\\
    &\quad+x(n-3)\\
    &\quad-3y(n-1)+2y(n-3).
\end{aligned}
\]

\stepheading{4. Collect the output terms}
Move the feedback terms to the left.
Their signs change.

\noteheading{Final answer}
\[
\boxed{\begin{aligned}
&y(n)+3y(n-1)-2y(n-3)\\
&\quad=x(n)+2x(n-1)+x(n-3).
\end{aligned}}
\]

\noteheading{Remember}
Count delays to each tapped branch, keep the gain signs, then combine the groups.

\SignalQuestion{9}{%
Given the two matrices representing the input $x(i,j)$ and output $y(i,j)$ of a
linear 2D filter: describe the $3\times3$ point spread function (PSF) or kernel
$h(i,j)$ that transforms $x(i,j)$ into $y(i,j)$.
Assume boundary conditions are zero, meaning pixels outside the matrix boundaries
of $x(i,j)$ and $y(i,j)$ are zero.
\begin{center}
\includegraphics[width=250pt]{2024-10-29_Q09_input-matrix-original.png}\par
\vspace{5pt}
\includegraphics[width=250pt]{2024-10-29_Q09_output-matrix-original.png}
\end{center}
\hfill(6p)
}

\SignalSolution{9}{}{%
\textit{Verified reference method, with the overlap calculations shown.}

\stepheading{1. Read one scaled impulse response}
An input pixel with value $A$ produces a copy of $A\,h$, centered at that pixel.
Overlapping copies add together.

Use $x(1,1)=112$. Its top output row is $(0,14,0)$;
no other input contributes to those three cells.
\[
\text{Top kernel row}
=\frac1{112}\begin{bmatrix}0&14&0\end{bmatrix}
=\begin{bmatrix}0&\frac18&0\end{bmatrix}.
\]

\stepheading{2. Find the center and direct neighbors}
The center output is $56$, so
\[
\text{Center weight}=\frac{56}{112}=\frac12.
\]
The left, right and lower neighbor outputs are $14$.
The zero top-corner weights just found rule out diagonal overlaps at these cells.
\[
\text{Each direct-neighbor weight}
=\frac{14}{112}=\frac18.
\]

\stepheading{3. Remove the overlapping contributions}
The lower corners of the output patch also receive values from other input pixels.
Subtract those first, then divide by $112$.

At $y(2,0)=10$, the input value $80$ contributes $80/8=10$.
\[
\begin{aligned}
\text{Lower-left weight}
&=\frac{10-80/8}{112}\\
&=\frac{10-10}{112}\\
&=0.
\end{aligned}
\]
At $y(2,2)=36$, the inputs $224$ and $64$ contribute $224/8$ and $64/8$.
\[
\begin{aligned}
\text{Lower-right weight}
&=\frac{36-224/8-64/8}{112}\\
&=\frac{36-28-8}{112}\\
&=0.
\end{aligned}
\]

\stepheading{4. Check an overlapping output}
At $(3,3)$, three neighboring inputs contribute:
\[
\begin{aligned}
y(3,3)&=\frac{224}{8}+\frac{64}{8}+\frac{176}{8}\\
&=28+8+22\\
&=58.
\end{aligned}
\]
This agrees with the given output matrix.

\noteheading{Final answer}
\[
\boxed{h(i,j)=\begin{bmatrix}
0&\frac18&0\\[3pt]
\frac18&\frac12&\frac18\\[3pt]
0&\frac18&0
\end{bmatrix}}
\]
A cross-shaped averaging kernel: center weight $1/2$, four direct neighbors $1/8$,
and zero corners. The weights sum to $1$.

\noteheading{Remember}
An impulse gives a scaled kernel. Subtract overlapping copies, then divide by the input value.
}
