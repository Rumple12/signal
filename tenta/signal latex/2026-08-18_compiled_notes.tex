\SignalQuestion{6}{%
\textbf{6.} Digital camera sensors typically capture only one color component
(red, green, or blue) per pixel using a Bayer filter array like the one shown
below. To reconstruct a full-color image, the missing color values at each pixel
are interpolated from neighboring pixels.
\begin{center}
\includegraphics[width=0.94\linewidth]{2026-08-18_Q06_bayer-original.png}
\end{center}
\begin{enumerate}[label=\alph*),leftmargin=15pt,itemsep=4pt,topsep=2pt]
\item Explain why the demosaicing (debayering) process necessarily involves a
trade-off between color fidelity and spatial resolution.\hfill(2p)
\item Describe in general terms how a simple demosaicing algorithm reconstructs
full RGB values from a Bayer-pattern image. \textit{Hint: refer to how missing
color values at each pixel are handled.}\hfill(2p)
\end{enumerate}
}

\SignalSolution{6}{a}{%
\noteheading{What we are doing}
We explain why reconstructing a full-color image creates a trade-off between
color fidelity and spatial resolution.

\stepheading{First: Understand the Bayer filter array}
A normal RGB image has three color values at every pixel:
\[
\text{Pixel}=(R,G,B).
\]
For example, a pixel might have:
\[
(R,G,B)=(200,100,50).
\]
Most conventional camera sensors using a Bayer filter array measure only
\textbf{one color per pixel}: red, green, or blue.

Example: RGGB Bayer pattern.
\begin{center}
\setlength{\tabcolsep}{0.5pt}
\begin{tabular}{cccccc}
\SensorCell{sensorred}{R}&\SensorCell{sensorgreen}{G}&\SensorCell{sensorred}{R}&\SensorCell{sensorgreen}{G}&\SensorCell{sensorred}{R}&\SensorCell{sensorgreen}{G}\\[1pt]
\SensorCell{sensorgreen}{G}&\SensorCell{sensorblue}{B}&\SensorCell{sensorgreen}{G}&\SensorCell{sensorblue}{B}&\SensorCell{sensorgreen}{G}&\SensorCell{sensorblue}{B}\\[1pt]
\SensorCell{sensorred}{R}&\SensorCell{sensorgreen}{G}&\SensorCell{sensorred}{R}&\SensorCell{sensorgreen}{G}&\SensorCell{sensorred}{R}&\SensorCell{sensorgreen}{G}\\[1pt]
\SensorCell{sensorgreen}{G}&\SensorCell{sensorblue}{B}&\SensorCell{sensorgreen}{G}&\SensorCell{sensorblue}{B}&\SensorCell{sensorgreen}{G}&\SensorCell{sensorblue}{B}\\[1pt]
\SensorCell{sensorred}{R}&\SensorCell{sensorgreen}{G}&\SensorCell{sensorred}{R}&\SensorCell{sensorgreen}{G}&\SensorCell{sensorred}{R}&\SensorCell{sensorgreen}{G}\\[1pt]
\SensorCell{sensorgreen}{G}&\SensorCell{sensorblue}{B}&\SensorCell{sensorgreen}{G}&\SensorCell{sensorblue}{B}&\SensorCell{sensorgreen}{G}&\SensorCell{sensorblue}{B}
\end{tabular}
\end{center}
Each square represents a sensor pixel that measures only the indicated color.
The pattern contains:
\begin{itemize}
\item 50\% green pixels;
\item 25\% red pixels;
\item 25\% blue pixels.
\end{itemize}
Green is sampled more frequently because it is particularly important for
perceived image brightness and detail.

\textbf{The problem:} How can we produce a full RGB image if each pixel measures
only one of the three colors?

The solution is called \textbf{demosaicing} (or debayering).
Demosaicing estimates the two missing color values at each pixel using
measurements from neighboring pixels.

\stepheading{Step 1: Understand the two concepts}
\textbf{Color fidelity} means how accurately the reconstructed image represents
the true colors of the scene.
For example, a red object should appear red, without unwanted green or blue
artifacts.

\textbf{Spatial resolution} means how well an image preserves small details,
sharp edges, and fine textures.
For example, the ability to distinguish thin lines or small text.

\stepheading{Step 2: Understand why there is a trade-off}
Imagine that the camera captures a sharp boundary between a red object and a
blue object.
Since each pixel measures only one color, the camera must estimate the missing
colors using neighboring pixels.
This creates two possible problems:

\textbf{Option 1: Preserve sharp details.}
If the algorithm preserves sharp edges and fine textures, its color estimates
may be inaccurate, producing false colors or colored edge artifacts.

\textbf{Option 2: Prioritize accurate, smooth colors.}
If the algorithm averages neighboring pixels more strongly to reduce color
artifacts, it may blur edges and remove fine details.

\stepheading{Step 3: Understand the fundamental limitation}
Each pixel measures only one color component, so the missing two components
must be estimated.
Consequently, we cannot always reconstruct both the exact colors and all the
original fine details, especially where colors change rapidly.
The algorithm must balance:
\[
\text{Color accuracy}\quad\longleftrightarrow\quad\text{Spatial detail}.
\]

\noteheading{Final answer for part (a)}
Demosaicing involves a trade-off because each sensor pixel measures only one
color component, so the other two must be estimated from neighboring pixels.
Preserving sharp spatial details may introduce incorrect colors or artifacts,
while smoothing to improve color fidelity may blur edges and reduce spatial
resolution.
}

\SignalSolution{6}{b}{%
\noteheading{What we are doing}
We describe how to reconstruct the missing RGB values from the Bayer pattern.

\stepheading{Step 1: Keep the measured color}
Each pixel already has one measured color, and we keep that value.
For example, at a red pixel:
\[
R=180.
\]
We do not yet know the green and blue values:
\[
(R,G,B)=(180,?,?).
\]
We must calculate the missing values.

\stepheading{Step 2: Estimate missing colors from neighbors}
A simple method is called \textbf{bilinear interpolation}.
Estimate a missing color by averaging nearby pixels that actually measured
that color.
Consider this $3\times3$ neighborhood centered on a red pixel:
\begin{center}
\setlength{\tabcolsep}{1pt}
\begin{tabular}{ccc}
\SensorSample{sensorblue}{B}{70}&\SensorSample{sensorgreen}{G}{100}&\SensorSample{sensorblue}{B}{90}\\[2pt]
\SensorSample{sensorgreen}{G}{110}&\SensorSample{sensorred}{R}{180}&\SensorSample{sensorgreen}{G}{130}\\[2pt]
\SensorSample{sensorblue}{B}{80}&\SensorSample{sensorgreen}{G}{120}&\SensorSample{sensorblue}{B}{100}
\end{tabular}
\end{center}
The center pixel is red. These numbers are example measured intensities.
We want to reconstruct the center pixel's full RGB value.

\stepheading{Step 2a: Red value}
The red value is already measured:
\[
\boxed{R=180}.
\]

\stepheading{Step 2b: Green value}
The nearest green pixels are above, below, left, and right of the center pixel.
Average these four values:
\[
\begin{aligned}
G&=\frac{100+120+110+130}{4}\\
 &=\frac{460}{4}\\
 &=115.
\end{aligned}
\]

\stepheading{Step 2c: Blue value}
The nearest blue pixels are at the four diagonal positions.
Average them:
\[
\begin{aligned}
B&=\frac{70+90+80+100}{4}\\
 &=\frac{340}{4}\\
 &=85.
\end{aligned}
\]

\stepheading{Step 3: Combine the values}
We now have all three color components:
\[
\boxed{(R,G,B)=(180,115,85)}.
\]
The original sensor pixel measured only red, but after demosaicing it has a
complete RGB representation.

\begin{center}
\colorbox{reconstructed}{\rule{0pt}{20pt}\hspace{24pt}}
\end{center}
Reconstructed pixel: $R=180$, $G=115$, $B=85$.
This is the resulting color in our example.

\stepheading{Step 4: Repeat for every pixel}
The same principle is used throughout the image, but the missing components
depend on the pixel's original color.

\textbf{Red pixel:} Keep $R$.
Estimate $G$ from horizontal/vertical green neighbors.
Estimate $B$ from diagonal blue neighbors.

\textbf{Blue pixel:} Keep $B$.
Estimate $G$ from horizontal/vertical green neighbors.
Estimate $R$ from diagonal red neighbors.

\textbf{Green pixel:} Keep $G$.
Estimate $R$ from two neighboring red pixels.
Estimate $B$ from two neighboring blue pixels, using the appropriate
horizontal/vertical direction.

At image boundaries, where some neighboring pixels are unavailable, the
algorithm requires special handling.
After processing all pixels, we obtain a complete RGB image.

\noteheading{What to remember}
Demosaicing estimates information that was never measured at each pixel.
It uses neighboring pixels and assumes nearby colors are usually similar.
This works reasonably well in smooth image regions, but can create errors
near sharp edges and fine textures.

\noteheading{Final answer for part (b)}
A simple demosaicing algorithm uses interpolation to estimate the two missing
color components at each pixel.
The measured color is preserved, while the missing colors are calculated by
averaging neighboring pixels of the corresponding color.
For example, at a red pixel, green is estimated from the four adjacent green
pixels and blue from the four diagonal blue pixels.
Repeat this process across the image to reconstruct full RGB values.
}
