{\large\textbf{Impulse response}}\par

Apply a unit impulse:
\[
x[n]=\delta[n].
\]
Starting from rest, the output is the impulse response:
\[
y[n]=h[n].
\]
Here, feedback from previous outputs makes the impulse response continue indefinitely.

\textbf{Final answer:} The system has an\par
\textbf{infinite impulse response (IIR).}
